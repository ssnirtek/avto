# Avto — система аренды автомобилей

Учебный веб-проект: информационная система проката автомобилей с каталогом машин, заявками на аренду и отчётами пользователей.

**Стек:** PHP, Yii2 (MVC), MySQL

## Возможности

- справочники: марки автомобилей, классы, категории, автомобили;
- заявки на аренду (`RentalRequests`) и отчёты пользователей (`UserReports`);
- управление пользователями и авторизация;
- CRUD-интерфейсы по всем сущностям с поиском и фильтрацией (search-модели).

## Сущности

`Cars`, `CarBrands`, `CarClasses`, `Category`, `RentalRequests`, `UserReports`, `User`

## Запуск

```bash
composer install
cp config/db-local.example.php config/db-local.php   # впишите свои данные подключения к MySQL
php yii serve
```

Данные подключения хранятся в `config/db-local.php`; он в `.gitignore` и в репозиторий не попадает.
